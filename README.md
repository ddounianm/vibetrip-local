# VibeTrip

Standalone local TanStack Start application.

## Requirements

- Node.js 22.12 or newer
- Bun 1.4 or newer

## Install

```sh
bun install
```

## Run locally

```sh
bun run dev
```

Open http://127.0.0.1:8081.

## Verify

```sh
bun run test
bun run lint
bun run build
```

The production build uses Nitro's Node.js server preset and is written to `.output`.
